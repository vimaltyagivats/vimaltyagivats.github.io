The work

BCS — Base Computer Software

The desk-side companion to a smart meter. BCS speaks the meter's own protocol over an optical port or communication module, so an engineer can commission a meter, pull its registers and prove what happened to it — without guesswork and without the manufacturer's black box.

Meter reading

Instantaneous parameters, billing registers, daily and monthly snapshots, and full load-survey download mapped to OBIS codes.

Configuration

Write demand integration period, load-survey interval, TOD/TOU zones, RTC sync, display sequence and billing dates with an audit trail of every change.

Tamper & events

Magnet, cover-open, reverse-current, missing-neutral and power-fail logs read out with timestamps — the evidence trail a utility needs.

Data export

Session data exported as CSV/JSON with meter serial and timestamp, ready for the billing system or an analysis sheet.

Bench & field parity

The same protocol layer drives the Windows-side tool and the Android app, so a reading taken on the bench matches one taken at the pole.

Diagnostics

Raw frame view, retry and CRC handling, and readable decode of every APDU — so a failed read is debugged in minutes, not days.

Field tool

The Android application

A phone, an IR probe and a technician. The app pairs with the meter, walks the reading sequence, stores the session offline and syncs when the network returns — the whole meter-reading round trip in a pocket.
