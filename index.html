The work

BCS — Base Computer Software

A Windows meter-analyzer application that speaks the meter's own protocol over an optical probe, GPRS or a wrapper link. It commissions meters, downloads every data profile they hold, charts what came back, upgrades firmware over the air, and prints the evidence — the desk-side half of a smart-metering deployment.

How a session runs

  1. 1ConnectSelect COM port, associate over optical HDLC, GPRS or wrapper — live meter or stored file
  2. 2DownloadAll profiles or a single one, with live progress and per-profile status
  3. 3StoreEach session filed by meter serial, timestamp and channel in View Manager
  4. 4AnalyseTables and bar/line graphs with min, max, average and latest per parameter
  5. 5ReportPrint or save PDF for name plate, instantaneous, billing, BLS, DLP and events

What it does

Data profiles

Name plate, instantaneous, billing, block load survey and daily load profile — each column mapped to its OBIS code and unit.

Graph engine

Any parameter as a bar or line chart with a tracking crosshair, range filter and a min / max / average / latest summary across the record set.

Reports & PDF

Formatted report per profile with the meter's identity block on top — printed directly or saved as PDF for the site file.

Meter configuration

Date & time, single action schedule, PCP, MD integration period and reset, metering and payment mode, relay control and timing, load limit.

FOTA firmware upgrade

Authenticated image transfer with block size, image size and first-missing-block tracking, a scheduled activation time and a full activity log.

View Manager

Every download kept and searchable by meter serial — date, folder, what was pulled and which channel it came over.

Security & association

Low- and high-level authentication with LLS and HLS key handling, and association settings per client role.

Android app data

Sessions captured on the phone in the field import straight into the desktop tool, so bench and field readings live in one place.

Event & tamper logs

Voltage, current, power, transaction, control, non-rollover and other event categories — each with timestamps and a meter health indicator.

Field tool

The Android application

A phone, a USB optical probe and a technician. The app detects the probe, associates as MR or US, pulls all twelve profiles, saves each as PDF, ships the session as a ZIP, and gates supply connect/disconnect behind an emailed one-time code.

Probe detection

Recognises the Silicon Labs CP210x optical probe over USB OTG and reports the link before a read starts.

MR / US association

Switch between meter-reader and utility-supplier client roles, each with its own authentication level.

PDF per profile

Save one profile or all twelve as PDF straight from the phone — the field copy of a meter reading.

Session ZIP

Every download kept on the device and shareable as a single ZIP to the office, from the session list.

OTP-gated relay control

Reading the supply state is free. Connect and disconnect each require a one-time code delivered to a registered mailbox — an audit trail on the one action that can cut a customer's power.

Offline first

Sessions are written to the device as they arrive, so a read completes with no network at the pole.
